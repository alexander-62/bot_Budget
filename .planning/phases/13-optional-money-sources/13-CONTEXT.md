# Phase 13 — Optional money sources

Дата: 2026-10-21. Пользователь поручил оформить через gsd-phase, планировать, реализовать и исправлять автономно. Обсуждённый сценарий согласован целиком.

## Locked decisions

- Источник денег — включаемая функция каждого профиля; false по умолчанию, включая personal и старые JSON-профили.
- Для бизнеса оператор включает «Учитывать источник денег» в форме профиля. Никакие реальные профили/таблицы агент не меняет.
- Источники ведутся в листе «Источники»: A источник, B активно, C порядок. Примеры: Счёт, Наличные, Карта. Допустимые значения читаются только из таблицы соответствующего бота.
- С включённой функцией: категория → подкатегория → источник → сумма. Повтор в той же категории снова предлагает выбор источника. С выключённой — прежний сценарий без дополнительного чтения листа.
- В расходах источник хранится в колонке I, заголовок «источник». H expense_id не перемещается. Старые строки остаются пустыми, история не заполняется догадками.
- Источник виден в подтверждении/последних расходах и меняется в редакторе сохранённой траты. Изменение суммы/комментария сохраняет источник; изменение источника сохраняет сумму/комментарий.
- Исторический неактивный источник не мешает изменению суммы. Новая запись/новый выбор требуют активный источник. Отключение функции не стирает уже сохранённые значения.
- Сводка остаётся общей по категориям. Балансы счетов и конвертация валют в эту фазу не входят.

## Runtime and rollout

Общий код и процессы профилей остаются прежними. Все проверки через tests/fakes без локальных секретов и живых расходов. Требуются регрессии выключенного personal, защиты stale callbacks, перестановок источников и безопасных write/update. Реальный бизнес-бот находится на другом компьютере; локальный коммит не равен доставке обновления туда.
