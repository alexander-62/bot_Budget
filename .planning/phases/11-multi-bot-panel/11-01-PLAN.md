# Общая панель

Цель: добавлять и управлять ботами из существующего Windows-интерфейса.

## Tasks

1. Выбор профиля, состояние, валюта, кнопки start/stop/restart, таблица и журнал выбранного бота. Сохранить текущий визуальный стиль, прокрутку и размеры под экран.
2. Форма добавления/редактирования: имя, стабильный ID, таблица, валюта, часовой пояс, путь Google credentials, маскированный токен. Токен не заполняется из хранилища обратно в форму.
3. До сохранения проверить Telegram getMe и схему Sheets через центральный адаптер. Ошибки безопасны и понятны, UI остаётся отзывчивым. Не применять запоздалые ответы к другому выбранному боту. Запретить редактирование работающего профиля.
4. Переключатель автозапуска для каждого бота, общий Windows startup. Создание третьего профиля через ту же форму.

## Verification

GUI/fake tests: маршрутизация команд и переключение профиля; stale callbacks; форма без утечки токена; неверный токен/схема не сохраняются; третий профиль создаётся без исходного кода. Визуальная проверка окна и формы при доступном desktop.

## Executable acceptance and recovery

Tasks 1–4: `.venv/Scripts/python.exe -m unittest tests.test_profile_ui tests.test_profile_validation tests.test_profile_sheets tests.test_desktop_ui -v`. Cancelled validation never persists; failed validation retains form and safe error; process startup during validation prevents reconfiguration. Profile save serializes with startup/runtime locks. Windows screenshot QA uses the window HWND, avoiding screen-coordinate captures.
