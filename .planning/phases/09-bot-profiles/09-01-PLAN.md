# Профили, валюта и совместимость

Цель: один код обслуживает изолированные конфигурации, личный бот продолжает работать.

## Tasks

1. Создать валидируемый реестр профилей с атомарной записью и отдельным хранилищем токенов (Windows DPAPI). Сохранить синтетический legacy-профиль personal без переписывания локальных секретов. Запретить некорректные идентификаторы, повторного Telegram-бота и общую таблицу разных бюджетов.
2. Загружать выбранный профиль до импорта обработчиков. Разделить runtime-пути; сохранить legacy-пути personal. Вынести форматирование валюты и часовой пояс в профиль, включая ежедневную сводку и дату записи.
3. Для новых профилей проверять доступ по числовому Telegram ID из собственного Users, сохранив совместимость текущего бота. Не менять ограничения редактирования расходов.

## Verification

Fake/temp-directory tests: конфигурации не смешиваются; новый профиль не наследует личный токен/таблицу; атомарный реестр; секрет отсутствует в JSON/repr; duplicate identity; RUB/EUR в расходах/сводках; доступ только по своему Users. Старые config/access/digest/expense tests проходят.

## Risks

Глобальные импорты конфигурации требуют выбора профиля до загрузки модулей. Изоляция процессов сохраняет раздельность кешей/сессий. Legacy остаётся совместимым и не мигрируется скрытно.
