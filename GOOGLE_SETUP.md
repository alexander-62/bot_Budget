# Подготовка Google Sheets

Создайте отдельную таблицу для бота. Для демонстрации используйте вымышленные суммы.

## Доступ и настройки

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект и включите Google Sheets API и Google Drive API.
2. Создайте сервисный аккаунт и JSON-ключ. Сохраните ключ локально как `credentials.json`; не загружайте его на GitHub.
3. В настройках доступа таблицы добавьте адрес сервисного аккаунта из поля `client_email` ключа с правом редактирования. Не включайте публичный доступ к таблице.
4. Скопируйте `.env.example` в `.env`. Укажите токен своего бота, ID своей таблицы и путь к ключу.

ID таблицы — часть её адреса между `/d/` и `/edit`:

```text
https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit
```

## Структура листов

Создайте пять листов. Заголовки — в первой строке. Сохраняйте порядок колонок: сервисы используют их позиции.

### `Users`

| A: username | B: user_id | C: digest_enabled | D: last_digest_date |
|---|---|---|---|
| your_telegram_username | | FALSE | |

Замените пример на свой username. При первом разрешённом обращении бот запишет Telegram user ID в B. Откройте чат и отправьте `/start`.

`FALSE` отключает сводку. Пустое значение или `TRUE` включает её; успешная отправка записывает дату в D для защиты от повторной отправки за тот же день.

### `Категории`

| A: категория | B: подкатегория | C: активно | D: порядок |
|---|---|---|---|
| Еда | Кафе | TRUE | 1 |
| Еда | Продукты | TRUE | 2 |

### `Лимиты_по_месяцам`

| A: категория | B: подкатегория | C: YYYY-MM |
|---|---|---|
| Еда | Кафе | 3000 |
| Еда | Продукты | 15000 |

Замените `YYYY-MM` на текущий месяц, например `2026-10`. Заголовок месяца должен быть текстом, а не датой. Для новых месяцев добавляйте колонки справа. Пары категория/подкатегория должны совпадать с листом `Категории`.

### `Траты_по_месяцам`

Создайте заголовки A–H в таком порядке:

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| дата | месяц | пользователь | категория | подкатегория | сумма | комментарий | expense_id |

Оставьте остальные строки пустыми: бот добавляет записи сам. Колонка H содержит идентификатор для проверки действий изменения и удаления. Не меняйте её вручную.

### `Список покупок Продукты`

В A1 укажите `товары`, ниже — по одному товару на строку. Остальные колонки не используются.

## Проверка

Запустите бот по [README](README.md). При старте он проверит листы и обязательные заголовки. Внесите вымышленную трату в тестовом чате и проверьте результат в таблице.

При ошибке доступа проверьте включение API в проекте сервисного аккаунта, права редактирования таблицы, ID таблицы и путь к ключу в `.env`.

`test_google.py` добавляет произвольную тестовую строку в первый лист. Не запускайте его на рабочей таблице.
