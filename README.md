# Bot Budget — бюджет в Telegram

Python-бот для личного и семейного бюджета: записывает расходы из чата в Google Sheets, показывает остатки по категориям и помогает вести общий список покупок. Таблица остаётся доступной для просмотра и настройки без отдельной панели администратора.

Проект разрабатывается с использованием AI. В репозитории представлены код приложения, автоматические тесты и инструкции для самостоятельного запуска.

## Возможности

- Ввод расхода: категория → подкатегория → сумма и необязательный комментарий.
- Автосохранение после ввода суммы; изменение, удаление и быстрый ввод следующей траты.
- Месячные лимиты, расходы и остатки по категориям; просмотр последних расходов.
- Общий список покупок с добавлением и удалением позиций.
- Вечерняя сводка общих расходов по категориям в 21:30 по Москве, включая напоминание в дни без записей.
- Доступ по списку пользователей в листе `Users`.
- Управление локальным процессом в Windows: запуск, остановка, обновление и значок состояния в трее.
- Windows-панель с логотипом, мониторингом подключений и автозапуском при входе в систему.

### Пример сценария

Вымышленный пример, не выгрузка пользовательских данных:

```text
Добавить трату → Еда → Кафе
Ввод: 350 кофе
Результат: расход 350,00 с комментарием «кофе» сохранён в таблице.
Далее можно изменить запись, добавить ещё в эту категорию
или начать новую трату с выбора категории.
```

## Технические решения

**Стек:** Python, aiogram 3, asyncio, gspread, aiohttp, Google Sheets; CustomTkinter для Windows-панели, pystray и Pillow для локального трея.

- Обработчики Telegram отделены от сервисов, клавиатур и состояния диалогов.
- Google Sheets-клиент и объекты листов кэшируются в едином адаптере.
- Сводка бюджета использует короткий кэш, сбрасываемый после изменения расходов.
- Блокирующие вызовы Sheets выполняются через `asyncio.to_thread`.
- Новые расходы добавляются через append; `expense_id` и проверка сохранённой строки помогают отклонять устаревшие действия изменения и удаления.
- Перед запуском проверяются настройки, наличие файла ключа и обязательная структура таблицы.
- Тесты используют подмены Google Sheets и Telegram; реальные ключи для них не нужны.

```text
bot.py / app.py       запуск, polling, HTTP-сервер
handlers/            маршрутизация Telegram и сценарии
keyboards/           кнопки и меню
services/            бюджет, расходы, доступ, Google Sheets
state/               состояние диалогов в памяти
scheduler.py         вечерняя сводка
scripts/             запуск тестов и проверка публикации
tests/               автоматические проверки
webapp/              статическая экспериментальная Web App
```

## Самостоятельный запуск

Используйте Python 3.12 или новее. Нужны собственный Telegram-бот, Google-таблица и ключ сервисного аккаунта Google.

1. Создайте окружение: `python -m venv .venv`.
2. Установите зависимости: `.venv/Scripts/python.exe -m pip install -r requirements.txt`. В Linux/macOS путь к Python окружения — `.venv/bin/python`.
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `SPREADSHEET_ID`, `GOOGLE_CREDENTIALS_FILE`. Ключ сервисного аккаунта храните локально в `credentials.json` либо укажите другой путь.
4. Подготовьте листы и доступ сервисного аккаунта по [инструкции Google Sheets](GOOGLE_SETUP.md).
5. Добавьте свой Telegram username в `Users` и запустите `.venv/Scripts/python.exe bot.py`.
6. Откройте чат с ботом и отправьте `/start`. Для остановки нажмите `Ctrl+C`.

`.env`, ключи Google, логи и служебные файлы процесса исключены из Git. Не добавляйте реальные расходы, переписку или снимки экрана с личными данными.

## Проверки

После установки зависимостей:

```powershell
.venv/Scripts/python.exe scripts/run_tests.py
.venv/Scripts/python.exe scripts/check_publication.py
```

Тестовые модули запускаются в отдельных процессах, чтобы их подмены библиотек не влияли друг на друга. Smoke-проверка использует настоящие установленные библиотеки. Команда не запускает polling и не обращается к живой таблице.

Проверка публикации ищет характерные секреты в отслеживаемых файлах, новых файлах вне `.gitignore` и доступной локально истории Git. Выводит только места совпадений, без значений. Это эвристическая проверка, а не гарантия отсутствия всех возможных секретов.

`test_google.py` — отдельная ручная интеграционная проба: она читает и изменяет первый лист реальной таблицы. В автоматические тесты не входит; используйте её только с отдельной тестовой таблицей.

## Управление в Windows

В текстовых полях формы работают **Ctrl+V**, **Shift+Insert** и **правая кнопка мыши → «Вставить»**, включая поле токена. В Windows сочетания Ctrl+V/C/X/A обрабатываются независимо от русской/английской раскладки. При пустом буфере выделенный текст сохраняется. Недоступный для изменения ID существующего профиля остаётся защищённым от вставки.

Пустое поле пути к ключу Google использует общий `GOOGLE_CREDENTIALS_FILE` из настроек программы (обычно `.env`; переменная окружения имеет приоритет). Относительный путь считается от папки программы. Например, `credentials.json` в установке `C:\bot_Budget` означает `C:\bot_Budget\credentials.json`. Новую таблицу нужно отдельно открыть сервисному аккаунту этого ключа с правом «Редактор». Проверка сообщает, если файл отсутствует, ключ некорректен, таблица недоступна или Google не отвечает.

### Несколько бюджетных ботов — v1.6.0

Главное окно — дашборд: у каждого бота своя карточка с названием, картинкой, временем работы и текущим статусом. Состояния всех ботов обновляются каждые 10 секунд, даже у свёрнутых карточек. Нажмите карточку, чтобы раскрыть настройки, управление, подключения, журнал и таблицу; повторное нажатие сворачивает подробности. Для следующего бота нажмите «Добавить бота». У каждого профиля свои Telegram-бот, таблица, участники, категории, валюта, часовой пояс и процесс. Текущий бот автоматически доступен как «Личный бюджет» (`personal`) с прежними настройками `.env` и валютой EUR.

Для бизнеса создайте нового бота в BotFather и отдельную таблицу по [инструкции](GOOGLE_SETUP.md#бизнес-бот-и-другие-профили). В форме задайте имя «Бизнес», ID `business`, ссылку на таблицу, валюту **RUB**, часовой пояс и токен. Путь к Google-ключу можно оставить пустым: используется общий ключ из текущей конфигурации. Ключу нужен доступ к новой таблице.

«Проверить и сохранить» проверяет Telegram и структуру Sheets в фоне, без добавления расходов. После сохранения выберите профиль и нажмите «Запустить». В новом боте разрешены только числовые Telegram ID из его собственного листа `Users`; все участники видят общие расходы этого бюджета. «Настройки» доступны и у работающего бота, включая личный бюджет. Смена названия сохраняется без перезапуска. Изменение токена, таблицы, часового пояса, ключа Google или учёта источника денег сначала проверяется; затем приложение останавливает только выбранного бота, сохраняет параметры и запускает его заново, ожидая готовности. Если новый запуск не удался, приложение пытается вернуть прежние настройки и запустить их; ошибка восстановления отображается явно. Остановленный бот после сохранения остаётся остановленным. Пустое поле токена сохраняет текущий токен.

Следующий профиль добавляется таким же способом без изменения Python-кода. Программного лимита профилей нет; одновременная нагрузка ограничена компьютером и квотами Sheets. Одна таблица и один Telegram-бот не могут принадлежать двум профилям.

Обычные настройки сохраняются локально в `profiles.json`. Токены новых ботов защищены Windows DPAPI в `.profile-secrets/` и доступны текущему пользователю Windows; при переносе на другой компьютер или аккаунт токены вводятся заново. Служебные файлы новых ботов — `.runtime/<id>/`, личного — прежние файлы в корне. Эти каталоги и реестр исключены из Git.

Для автоматического запуска включите общий автозапуск Windows и отметьте нужные профили переключателем в панели. При входе запускаются только отмеченные профили; закрытие окна не останавливает ботов.

Прямые команды (из папки проекта):

```powershell
.venv/Scripts/python.exe manage_bot.py start --profile business
.venv/Scripts/python.exe manage_bot.py status --profile business
.venv/Scripts/python.exe manage_bot.py stop --profile business
.venv/Scripts/python.exe manage_bot.py start-autostart
```

Без `--profile` команды относятся к `personal`. Обновления исходного кода общие для всех профилей; чтобы все процессы использовали новую версию, перезапустите каждый запущенный профиль.

### Картинка каждого бота — v1.6.2

Выберите бота в панели и нажмите **«Картинка»** под его изображением. Поддерживаются PNG, JPEG, WebP и BMP до 10 МБ. Панель сохраняет собственную квадратную копию; исходный файл затем можно переместить или удалить. **«Сбросить»** возвращает стандартную картинку.

При выборе другого профиля показывается его изображение. Картинку можно менять у работающего бота и у личного профиля без изменения токена, таблицы или настроек расходов. Перед выбором изображения закройте открытое окно настроек.

Это картинки только для локальной панели и её значка окна. Аватары Telegram настраиваются отдельно. Файлы хранятся в `.profile-images/`, привязка — в `profiles.json`; оба пути исключены из Git. Выбирайте картинки на компьютере с панелью либо переносите эти файлы вместе с её настройками.

### Источник денег — включаемая функция v1.6.1

В форме добавления/настройки бота есть флажок **«Учитывать источник денег»**. По умолчанию он выключен, включая старые профили и личный бюджет. Чтобы включить его для бизнеса, подготовьте [лист «Источники» и колонку I](GOOGLE_SETUP.md#источник-денег-необязательно), затем включите флажок и сохраните настройки. Работающий бот перезапустится автоматически; остановленный можно запустить кнопкой «Запустить».

При включённой функции сценарий ввода: категория → подкатегория → источник → сумма. Повтор в той же категории снова предлагает источник. Источник показывается в подтверждении и последних расходах; после «Изменить» доступна кнопка «Изменить источник». Изменение источника сохраняет сумму и комментарий, изменение суммы сохраняет прежний источник.

Старые расходы остаются без источника и показываются как «Не указан». Отключение или переименование источника в справочнике не меняет историю. После отключения функции значения в колонке I сохраняются, дополнительного шага в чате нет. Категорийная сводка остаётся общей.

Первый переход на панель: выполните `bot.bat update`, чтобы установить новую зависимость CustomTkinter. Затем откройте `bot.bat` двойным щелчком — появится панель и запустится бот. Команда `bot.bat ui` открывает только панель; `bot.bat ui --minimized --start-bot` запускает бота и панель в фоне.

Панель показывает состояние процесса, фактическую версию запущенного бота, время работы и доступность Telegram/Google API. Проверки идут в фоне каждые 10 секунд и не блокируют окно. Доступность API по HTTPS не означает проверку прав на конкретную Google-таблицу — её бот проверяет при запуске. Кнопки запуска, остановки и перезапуска используют существующий менеджер процессов.

Переключатель «Запускать вместе с Windows» добавляет команду в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` только для текущего пользователя и этой папки установки. Администраторские права не требуются; при выключении удаляется только собственная запись. Бот и свёрнутая панель стартуют при входе пользователя, а не до входа в Windows.

Если при входе сеть ещё не готова, панель дождётся доступности Telegram и Google и затем отправит команду запуска. Ошибки настроек бота не вызывают бесконечный перезапуск: их можно посмотреть в логе.

Закрытие окна сворачивает панель в трей. Двойной щелчок по значку или пункт «Открыть панель» показывает то же окно. Если трей недоступен, окно остаётся доступным на панели задач. «Выйти из панели» завершает только панель: бот и трей продолжают работать. При повторном открытии второй экземпляр окна не создаётся. Карточка и значок окна используют картинку выбранного профиля; стандартная картинка и общий трей используют `logo.png`.

```bat
bot.bat ui
bot.bat start
bot.bat start --foreground
bot.bat status
bot.bat restart
bot.bat stop
bot.bat update
bot.bat tray
bot.bat stop-tray
```

`start` запускает бота в фоне и значок в трее, логи пишутся в `bot.log`. Если порт занят другим приложением, менеджер выбирает следующий свободный. `update` получает изменения с GitHub, сохраняет список работающих профилей, закрывает панель/трей, останавливает сохранённые профили, выполняет `git pull --ff-only origin main`, устанавливает зависимости и запускает только ранее работавшие профили. Обновление считается завершённым после проверки версии и готовности Telegram каждого бота. Панель и трей восстанавливаются, если работали до обновления. Для обновления нужен настроенный `origin` и ветка `main`.

Повторное нажатие ярлыка не запускает второй экземпляр из той же папки: менеджер блокирует одновременные старты, а сам бот держит отдельную блокировку до завершения процесса. Она действует и при прямом запуске `bot.py` или `app.py`, даже если `.bot.pid` отсутствует. У значка в трее такая же защита. Файлы `.bot.lock`, `.bot-start.lock`, `.tray.lock`, `.tray-start.lock` могут оставаться после остановки — это нормально: ОС освобождает блокировку автоматически, в том числе при аварийном завершении. Удалять эти файлы у работающего бота не нужно.

Команда «Перезапуск» в чате также обновляет код из `origin/main`. Текущая модель доступа предназначена для доверенного круга пользователей.

## Границы проекта

- Бот предназначен для небольшого общего бюджета. Допущенные пользователи видят общие данные; изоляции отдельных семей и ролей администратора нет.
- Доступ проверяется по Telegram username; переход к неизменяемому user ID — направление дальнейшего развития.
- Состояние диалогов находится в памяти и сбрасывается при перезапуске.
- Google Sheets имеет сетевые задержки и ограничения API; транзакционной базы данных здесь нет. Одновременные внешние изменения строк требуют осторожности.
- Web App пока представляет собой статическую тестовую страницу. Основной интерфейс — чат. Для открытия Web App внутри Telegram нужен публичный HTTPS-адрес; localhost предназначен для локальной проверки.
- Дата расходов, текущий месяц и ежедневная сводка учитывают часовой пояс профиля (`Europe/Moscow` по умолчанию).

Дальнейшие улучшения: авторизация по user ID, отдельные административные права, база данных для конкурентных операций и полноценный интерфейс Web App.


### Единое хранение настроек личного бота

При первом сохранении настроек старого личного профиля значения таблицы и ключа Google автоматически переносятся из действующей конфигурации в `profiles.json`, а Telegram-токен — в `.profile-secrets/personal.bin` с защитой Windows DPAPI. Поле `managed_settings` отмечает завершённый перенос. После этого бот и панель читают настройки личного профиля из тех же хранилищ, что и настройки остальных ботов. Старый `.env` не удаляется; он остаётся источником общих параметров сервера и общего ключа Google, но больше не переопределяет персональный токен и таблицу.

Флаг совместимости `legacy` у личного профиля сохраняет прежние правила доступа и схему существующей таблицы. Личный журнал и runtime-файлы остаются на прежнем месте, чтобы перенос настроек не терял журнал и не создавал второй процесс. Новые профили используют собственные папки `.runtime/<id>`.


В системном трее Windows предусмотрен один общий значок **Bot Budget** для всех профилей. Двойной щелчок открывает панель; меню значка позволяет открыть панель, проверить статус и закрыть значок. Закрытие панели крестиком скрывает её в трей, если значок работает, иначе сворачивает на панель задач. Кнопка «Выйти из панели» закрывает только окно управления; работающие боты продолжают работу. Кнопки «Картинка» и «Сбросить» в раскрытой карточке появляются при наведении на изображение и скрываются, когда указатель покидает область изображения и кнопок.


## Настройки бюджета в Google Sheets (v1.7.0)

В Telegram откройте **⚙️ Настройки** (или `/settings`). Настройки общие для всех разрешённых участников бюджета:

- **Валюта** — EUR или RUB. Перед сменой бот просит подтверждение: меняется обозначение всех сумм, включая историю, без пересчёта по курсу. Это единая валюта бюджета, не мультивалютный учёт.
- **Месячные лимиты** — явно включить или выключить. Выключение сохраняет лимиты в таблице, оставляет запись трат и месячные отчёты без потолка, остатка и предупреждений о превышении. Кнопка меню меняется на «Расходы за месяц».
- **Создать категорию** — название и первая подкатегория. До второго шага ничего не записывается.
- **Добавить подкатегорию** — выбрать существующую активную категорию и ввести название. Дубликаты проверяются без учёта регистра и лишних пробелов, включая неактивные строки. Название — 1–64 символа, без переносов строк.

«Назад» возвращает в меню настроек, «Отмена» или `/cancel` завершает диалог. Сессия действует 15 минут; старые кнопки и кнопки другого пользователя не могут изменить настройки. Переход к другому действию основного меню завершает незаконченный диалог. Переименование и архивирование из бота в эту версию не входят.

При первом запуске обновлённого бота автоматически создаётся лист `Настройки` со столбцами `Параметр`, `Значение`:

| Параметр | Значение |
|---|---|
| `currency` | `EUR` или `RUB` |
| `monthly_limits_enabled` | `TRUE` или `FALSE` |

Недостающая валюта переносится из прежнего профиля; лимиты по умолчанию остаются включены. Существующие значения не перезаписываются. Ошибочные значения или дубликаты параметров требуют исправления таблицы — бот не подменяет их значениями по умолчанию. Проверка подключения в панели не создаёт лист и не меняет данные.

Таблица — единственный рабочий источник этих двух настроек. Поле `currency` в старом `profiles.json` сохраняется только как исходное значение для первичного переноса. Валюта в форме нового профиля задаёт это начальное значение. Для существующего профиля используйте кнопку **«Валюта бюджета — Google Sheets»** в настройках панели; окно читает и сохраняет валюту в таблице без перезапуска. В Telegram изменения из таблицы/панели подхватываются при следующем действии с кешем до 5 секунд, в вечерней сводке — перед отправкой.

Месячные итоги включают траты по неактивным и удалённым из справочника категориям. Для новых трат предлагаются только активные категории. Пустой/отсутствующий лимит означает «не задан» (`—`), числовой ноль — настоящий нулевой лимит. Если хотя бы одна участвующая подкатегория не имеет лимита, общий лимит и остаток показываются как `—`, чтобы не выдавать частичный потолок за полный. При выключенных лимитах лист `Лимиты_по_месяцам` не читается и не требуется; для включения он должен иметь корректные заголовки.

Токены, Google-ключи, привязка к таблице, часовой пояс, автозапуск и остальные параметры запуска остаются на машине. Секреты в лист `Настройки` не помещайте. Перед обновлением сохраните резервную копию таблицы; миграция добавляет только лист/недостающие параметры, расходы не меняет. Старую версию после миграции не запускайте: она продолжит брать валюту из локального профиля.

Записи справочника добавляются через RAW append; повтор после успешной записи не создаёт дубль. Проверки сериализуются внутри процесса бота. Google Sheets не обеспечивает транзакционную уникальность между независимыми процессами и ручными правками: не создавайте одну и ту же категорию одновременно из нескольких копий бота/редакторов.


### Исправления обновления (v1.7.1)

Пустой лист `Настройки`, который Google Sheets возвращает как `[[]]`, теперь автоматически получает заголовки и недостающие исходные параметры. Существующие непустые параметры и финансовые записи не перезаписываются.

Обновлятор хранит незавершённый список профилей в локальном `.update-state.json`. Если запуск или установка зависимостей прервались, после устранения ошибки выполните `bot.bat finish-update`: сохранённые профили будут запущены и проверены повторно. Повторная подготовка не теряет этот список. Изначально остановленные профили обновлятор не включает, даже если у них включён автозапуск Windows.

Если старый бот запущен с повышенными правами, обычный процесс Windows не может его остановить: завершите старый экземпляр с соответствующими правами. Панель старше 1.7.1 перед первым обновлением может потребовать ручного выхода через «Выйти из панели»; новая панель закрывается по запросу обновлятора, если не занята сохранением настроек.
